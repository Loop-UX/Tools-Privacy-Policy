# Loop UX Tools Privacy Policy

The privacy policies for the Chrome extensions and Google Workspace add-ons that Loop UX makes for its own staff. Each store listing of these tools links to its tool's section.

Status: live. GitHub Pages serves the pages from `main` at https://loop-ux.github.io/Tools-Privacy-Policy/

## What the pages are

- [`index.html`](index.html): the list of the policies. [`chrome-extensions/`](chrome-extensions/index.html) and [`workspace-add-ons/`](workspace-add-ons/index.html): one policy each, with a section for every tool.
- Questions about the policies: data@loop-ux.com

## Working on it

Open this folder with an AI coding agent: [`AGENTS.md`](AGENTS.md) is its manual. To set up a computer, follow the Handbook's [SETUP.md](https://github.com/Loop-UX/Handbook/blob/main/SETUP.md). The repository runs no checks of its own; the `tools-privacy-policy` skill checks the pages before a push.
